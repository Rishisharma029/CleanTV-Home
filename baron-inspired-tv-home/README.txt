Baron-inspired TV Home update — version 3.5

Installed on the Changhong AI PONT TV as com.gathin.tvhome version 3.5 (versionCode 16). Home starts successfully. Zee News now occupies the former Castle slot in the seven-app dock.

Storage button
A standalone Storage icon now sits beside Inputs in the top bar. It reports the TV's live /data capacity in its focus details (used and free), opens Android Storage settings on select, and opens the same system cleanup screen on long-press with the Clear cache path. The Inputs menu no longer contains Storage. Android controls cache cleanup; the launcher does not delete app data or kill running apps. The TV does not expose a general one-tap device optimizer to this launcher.

App controls
Hold OK/Select on a dock app to open its app menu. Choose Move one place up, Move one place down, Move to first, or Move to last. The existing Move option is also available for directional reorder mode. Tile menus are enabled by default so holding an app opens these actions rather than Android's app-info screen.

Catalog feed
The Watchmode latest-catalog feed remains disabled at the user's request. No catalog requests are made and no recommendation shelf is shown. The existing Watchmode key remains in the launcher's private preferences; it was not copied into this document or the APK.

Build: release APK, SDK 34, package com.gathin.tvhome, version 3.5 (versionCode 16), size 533,605 bytes. The 3.4 APK is retained as baron-inspired-tv-home-3.4-previous.apk; version 2.7 and 2.8 are also retained.

Installation: updated in place; Home resolves to com.gathin.tvhome/.MainActivity and is running. Preview: tv-home-preview.png.

USB debugging remains enabled at the user's instruction and will stay on until the user asks to turn it off.
